# Blinky’s Egg Garden

Static community match-3 game: Adventure, Endless Zen and Daily Challenge.
Upload these files together, keeping all files together. index.html belongs at the root of the folder published by GitHub Pages. No build, API key or server is needed. Keep the credits and asset licence.

Daily Challenge v1 uses 30 moves, a shared UTC date seed, deterministic refills and repeatable replays. Reset: 00:00 UTC. Completed best scores are saved locally; Copy Result copies your best run for that date. No online leaderboard or score verification. Progress does not transfer across browsers or domains.
